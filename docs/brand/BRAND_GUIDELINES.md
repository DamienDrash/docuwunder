# DocuWunder — Corporate Identity v1.0

## Brand idea

DocuWunder makes the power of Paperless-ngx understandable and approachable for people who do not want to manage a technical interface.

**Brand promise:** Documents are easy to capture, find and organize without losing control of the self-hosted archive.

**Claim:** Deine Dokumente. Ohne Technikstress.

**Functional descriptor:** Die freundliche, unabhängige Oberfläche für Paperless-ngx.

## Positioning

DocuWunder is not a limited "lite" edition. It is a consumer-oriented client that progressively reveals advanced Paperless-ngx capabilities while keeping everyday tasks clear.

## Brand personality

- Friendly, not childish
- Calm, not sterile
- Competent, not technical
- Premium, not luxurious
- Honest, not promotional

## Logo concept

The symbol combines an archive tray, a document and a restrained four-point sparkle. The archive tray represents order, the document represents the product domain, and the sparkle represents the unexpectedly easy experience. It deliberately avoids the Paperless-ngx leaf motif.

## Color system

| Role | Name | Hex | Guidance |
|---|---|---:|---|
| Friendly accent | Primary Mint | `#8EE5DA` | Highlights, selected states, focus rings and illustrations |
| Accessible action | Action Teal | `#147E73` | Primary buttons, links and active controls |
| Main text | Deep Navy | `#0D1B2A` | Headlines, body text and navigation |
| Secondary text | Slate | `#5E6B78` | Metadata and helper text |
| Background | Soft Fog | `#F7FAFA` | Main application background |
| Border | Cloud | `#E2EFED` | Dividers and input borders |

`#8EE5DA` is intentionally not used behind white body text. Use Deep Navy on Mint. Use white text on Action Teal.

## Typography

- Brand and marketing headlines: **Manrope**
- Web UI and long-form text: **Inter**
- iOS UI: system typography with Dynamic Type
- Android UI: platform typography and scalable text

## Corporate communication

### Voice

1. **Friendly:** Address people directly and without condescension.
2. **Clear:** Use the user-facing word before the technical term.
3. **Reassuring:** Explain what happened and what the user can do next.
4. **Honest:** Make privacy and security claims only when the architecture guarantees them.

### Preferred terminology

| Technical wording | DocuWunder wording |
|---|---|
| Instance | Archiv |
| Endpoint | Serveradresse |
| Authentication token | Zugangsschlüssel |
| Correspondent | Absender |
| Document type | Dokumentart |
| Consume document | Dokument hinzufügen |
| Metadata | Angaben |
| Workflow | Automatisierung |

### Example error message

**Avoid:** `Request failed with status code 401.`

**Use:** `Die Anmeldung wurde abgelehnt. Prüfe deinen Benutzernamen und deinen Zugangsschlüssel.`
