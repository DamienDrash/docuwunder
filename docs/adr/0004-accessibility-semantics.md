# ADR 0004: Semantische Bedienelemente fuer Meilenstein B

Datum: 2026-08-02

DocuWunder migriert klickbare div/span-Elemente domainweise auf native Controls, bevorzugt `button type="button"`. `DWStile.buttonReset` erhaelt die Optik; Semantik, Fokus und Tastaturaktivierung kommen vom Browser. Manuelle Screenreader- und Geraetetests bleiben erforderlich.
